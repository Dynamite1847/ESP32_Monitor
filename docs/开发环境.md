# ESP32-S3 桌面控制台：开发环境

> 更新日期：2026-08-18

## 1. 当前环境

- macOS Apple Silicon
- ESP-IDF v5.5.5
- Python 3.13 独立虚拟环境
- CMake 4.4.2
- Ninja 1.13.2
- Xtensa ESP32-S3 工具链 14.2.0_20260121
- esptool.py v4.12.0
- LVGL 9.5.0
- esp_lvgl_adapter 0.5.3
- esp_lcd_touch_gt911 1.2.1

ESP-IDF 位置：

```text
${HOME}/esp/v5.5.5/esp-idf
```

每次新建终端后先激活环境：

```bash
source "${HOME}/.espressif/tools/activate_idf_v5.5.5.sh"
```

## 2. 开发板配置

| 配置 | 用途 | 当前状态 |
|---|---|---|
| `WAVESHARE_ESP32_S3_TOUCH_LCD_4_3` | 现有 4.3 无后缀开发板 | 默认，显示、触摸、中文、滑动与 BLE 已验证 |
| `WAVESHARE_ESP32_S3_TOUCH_LCD_4_3_B` | 已购 4.3B 最终设备 | 官方参数已建档，待到货实机验证 |

两款板共用 ESP32-S3 N16R8、800×480 RGB 屏及主要显示和触摸引脚。工程仍保留独立的板级配置，新板到货后会核对背光、触摸复位、RTC、TF 卡和其他外设。

## 3. 下载与依赖策略

本项目默认优先使用官方完整包：

- 下载完整 ESP-IDF 离线归档，保留所有 ESP32-S3 工具链和组件缓存。
- 保留微雪官方完整示例、恢复固件、依赖、图片和硬件资料。
- 不为节省数 GB 空间主动裁剪官方包。
- 只有明确需要精简包时，才改用按需下载。

ESP-IDF、工具链和项目依赖已经安装到开发环境。下载目录中的归档包不参与日常编译，是否保留由用户自行决定；工程不再依赖 `eim_config.toml`，只保留可提交的示例配置。

## 4. 连接与烧录规则

- 开发和日志优先使用标有 `UART` 的 Type-C 接口。
- 第一次烧录前先读取芯片型号、Flash 容量和 MAC 地址。
- 开发板配置与实物不一致时停止烧录。
- 保留官方恢复固件，需要时可将开发板恢复到出厂演示状态。
- 日常修改先完成编译；只在开发板在线且型号已核对时烧录。
