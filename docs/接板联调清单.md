# ESP32-S3 桌面控制台：接板联调清单

> 用途：开发板连接后按固定顺序完成第一次验证，降低接错接口和误刷配置的风险。

## 1. 连接前

- 确认目标板型号：当前 4.3 无后缀版，或到货后的 4.3B。
- 使用数据线连接板载 `UART` Type-C 接口。
- 暂不插 TF 卡，也不连接 CAN、RS485、继电器或其他外设。
- 编译配置应与实际板型一致。首次仍使用默认的 4.3 无后缀配置。

## 2. 只读识别

连接后先完成以下检查，不写入 Flash：

1. 找到新增串口并记录端口名。
2. 读取芯片型号、芯片版本、Flash 容量和设备 MAC。
3. 确认目标为 ESP32-S3，Flash 识别为 16MB。
4. 保存识别结果到开发记录。

识别值与预期不一致时停止烧录，先核对板型和线材。

## 3. 首次烧录

只读识别通过后：

1. 烧录已经通过编译的首版固件。
2. 打开串口日志，确认屏幕、触摸和界面任务初始化成功。
3. 首次联调配置会保持背光常亮，方便排查；该配置不能作为办公室日常版本。
4. 遇到黑屏时先看日志，再检查背光与 RGB 初始化，不反复擦除整片 Flash。

## 4. 显示与触摸验收

- 屏幕方向为 800×480 横屏。
- 红、绿、蓝和灰阶色序正确，无明显闪烁或撕裂。
- 首页、市场、系统、控制、AI、媒体和页面库都能从程序坞进入。
- 页面库中的设置与诊断可以打开，其他二期入口保持禁用。
- 六个日常页面可以左右滑动，程序坞和进度条区域不会误触发换页。
- 系统页 CPU 与内存曲线每 2 秒增加一个点，切换页面后历史仍保留，断开蓝牙后清空。
- 四角、边缘和中心触摸位置一致，没有 X/Y 互换或镜像。
- 快速连续切页 50 次不重启、不花屏。

## 5. 隐私与亮灭屏验收

完成 BLE 服务后再执行：

- 启动时保持熄屏和触摸锁定。
- 仅连接 Wi-Fi 不亮屏。
- 已绑定 Mac 完成认证后亮屏并回到首页。
- 蓝牙断开后立即关背光、禁用触摸并清除系统、控制、AI 和媒体数据。
- 心跳停止超过 6 秒时执行相同锁定流程。
- Mac 锁屏或睡眠时主动锁定设备。
- 未认证连接无法触发按钮、滑块和快捷动作。

## 6. Wi-Fi 与公共数据验收

完成蓝牙认证后从 Mac 菜单栏助手配置设备 Wi-Fi：

- ESP32 连接 2.4GHz 网络，状态栏和设置页显示已连接、RSSI 与 IPv4 地址。
- 断开路由器后进入重试，网络恢复后自动重连；重连期间蓝牙与触摸保持响应。
- NTP 对时成功后首页时间正确，时区为中国标准时间。
- 配置和风天气专用 API Host、API Key 和坐标，首页出现当前天气、未来 6 小时、今明两天；有有效预警时出现预警条。
- 市场页显示上证综指、深证成指、创业板指、科创 50、沪深 300 和中证 500，数值与交易所网页方向一致。
- 天气或行情接口故障时保留最近有效数据，诊断与 BLE 心跳不受影响。

## 7. Mac 控制与 AI 验收

- 控制页六个快捷键分别验证 Safari/Chrome 后退、前进、刷新、新标签、系统截屏和终端。
- 媒体页验证上一首、播放/暂停、下一首、静音和音量增减，音量条随 Mac 更新。
- Codex 页面显示真实额度窗口与当前任务数量，不出现提示词、回答和项目路径。
- Claude Code 运行时任务数增加；可选状态行启用后，有额度字段时显示 5 小时与 7 天用量。
- Mac 锁屏后以上私密状态全部清空。

## 8. microSD 验收

显示、触摸和背光通过后再插入 FAT32 存储卡并重启；当前固件未启用 exFAT：

- 串口显示 microSD 已挂载，卡内自动出现 `desk_console/logs`、`screenshots` 和 `assets`。
- `logs` 中生成当前启动日志，连续操作界面时没有明显卡顿或触摸延迟。
- 未插卡启动时固件仍能进入主界面，存储任务会等待后重试，不触发格式化。
- 在没有写入动作时拔卡，确认日志写入失败后系统继续运行；重新插卡后能够恢复挂载。
- 连续写入期间断电，再次启动后 FAT 文件系统仍能挂载，已有日志最多损失最后一个批次。
- 验证背光开关不会使 SD 掉线，SD 重试也不会改变背光状态。

## 9. 4.3B 到货后的补充项

- 单独切换到 4.3B 编译配置并重复全部显示、触摸和背光测试。
- 验证板载 RTC 和后备电源保持时间。
- 重复验证 TF 卡插拔、读写和 CH422G 状态保持。
- CAN、RS485、隔离输入输出留到需要相关玩法时测试，不阻塞一期桌面控制台。
