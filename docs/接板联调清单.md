# ESP32-S3 桌面控制台：接板联调清单

> 用途：开发板连接后按固定顺序完成第一次验证，降低接错接口和误刷配置的风险。

## 1. 连接前

- 确认目标板型号：当前 4.3 无后缀版，或到货后的 4.3B。
- 使用数据线连接板载 `UART` Type-C 接口。
- 暂不插 TF 卡，也不连接 CAN、RS485、继电器或其他外设。
- 编译配置应与实际板型一致。首次仍使用默认的 4.3 无后缀配置。

## 2. 只读识别

连接后先完成以下检查，不写入 Flash：

1. 找到新增串口并记录端口名。
2. 读取芯片型号、芯片版本、Flash 容量和设备 MAC。
3. 确认目标为 ESP32-S3，Flash 识别为 16MB。
4. 保存识别结果到开发记录。

识别值与预期不一致时停止烧录，先核对板型和线材。

## 3. 首次烧录

只读识别通过后：

1. 烧录已经通过编译的首版固件。
2. 打开串口日志，确认屏幕、触摸和界面任务初始化成功。
3. 首次联调配置会保持背光常亮，方便排查；该配置不能作为办公室日常版本。
4. 遇到黑屏时先看日志，再检查背光与 RGB 初始化，不反复擦除整片 Flash。

## 4. 显示与触摸验收

- 屏幕方向为 800×480 横屏。
- 红、绿、蓝和灰阶色序正确，无明显闪烁或撕裂。
- 首页、市场、系统、控制、AI、媒体和页面库都能从程序坞进入。
- 六个日常页面可以左右滑动，程序坞和进度条区域不会误触发换页。
- 四角、边缘和中心触摸位置一致，没有 X/Y 互换或镜像。
- 快速连续切页 50 次不重启、不花屏。

## 5. 隐私与亮灭屏验收

完成 BLE 服务后再执行：

- 启动时保持熄屏和触摸锁定。
- 仅连接 Wi-Fi 不亮屏。
- 已绑定 Mac 完成认证后亮屏并回到首页。
- 蓝牙断开后立即关背光、禁用触摸并清除系统、控制、AI 和媒体数据。
- 心跳停止超过 6 秒时执行相同锁定流程。
- Mac 锁屏或睡眠时主动锁定设备。
- 未认证连接无法触发按钮、滑块和快捷动作。

## 6. 4.3B 到货后的补充项

- 单独切换到 4.3B 编译配置并重复全部显示、触摸和背光测试。
- 验证板载 RTC 和后备电源保持时间。
- 验证 TF 卡插拔和读写，再决定是否启用存储功能。
- CAN、RS485、隔离输入输出留到需要相关玩法时测试，不阻塞一期桌面控制台。
