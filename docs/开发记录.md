# ESP32-S3 桌面控制台：开发记录

## 2026-08-16：工程启动

### 已完成

- 安装并验证 ESP-IDF v5.5.5 完整离线环境。
- 锁定 LVGL 9.5.0、esp_lvgl_adapter 0.5.3 和 GT911 触摸驱动 1.2.1。
- 核对微雪 4.3 与 4.3B 最新官方 LVGL 9 示例。
- 建立 `board` 适配层，提供 4.3/4.3B 编译时选型。
- 实现 800×480 RGB 屏、GT911 触摸与 CH422G 背光开关。
- 建立 LVGL 横屏界面骨架，包含六个日常页面、页面库、程序坞和左右滑动。
- 建立双 OTA 分区表，每个应用分区 5MB，并预留约 5.9MB 设备存储区。
- 完成第一次全量编译，主固件约 892KB。

### 当前决策

- 日常开发先使用现有 4.3 无后缀板。
- 4.3B 作为最终硬件，到货后独立验证板载外设与供电。
- 联调阶段临时允许无蓝牙时亮屏，便于检查显示和触摸。
- 蓝牙认证和心跳状态机完成后，生产配置将恢复为启动锁定、蓝牙断开立即熄屏。

### 下一步

1. 用 UART Type-C 连接现有 4.3 板。
2. 读取芯片型号、Flash 容量和设备 MAC，不改写 Flash。
3. 核对成功后烧录首版固件。
4. 检查屏幕方向、色彩、触摸坐标、滑动切页和背光开关。

## 2026-08-16：无开发板准备基线

### 已完成

- 建立 `app_model`，统一管理连接、天气、指数、系统、控制条、AI 和媒体状态。
- 建立 `privacy`，实现启动锁定、认证、心跳、断开、Mac 锁屏与睡眠状态转换。
- 心跳周期设计为 2 秒，超时阈值为 6 秒；超时动作包含关背光、禁用触摸和清理私有状态。
- 建立 `ble_protocol`，实现版本化帧、消息编号、最大 512 字节负载和 CRC-16/CCITT-FALSE 校验。
- 完成蓝牙配对、应用层挑战认证、GATT 分片和业务字段协议草案。
- 页面改为从统一状态模型读取数据，加入中文首页、六指数、系统、控制条、AI、媒体和页面库。
- 启用 LVGL 内置 Source Han Sans SC 16px 中文字体；大号数字继续使用 Montserrat。
- 增加主机侧测试，覆盖隐私正常流程、认证失败、心跳超时、CRC、帧篡改和私有数据清理。
- 增加接板联调清单和一键编译前检查脚本。

### 验证结果

- 主机侧自动测试通过。
- ESP-IDF 全量编译通过，无需开发板参与。
- 固件镜像约 1.14MB，5MB 应用分区剩余 78%。
- DIRAM 使用约 143KB，占可用容量 41.87%。
- 当前未连接串口，未读取设备信息，也未执行烧录。

### 容量结论

- 当前功能不需要 microSD 卡。
- 分区已预留约 5.9MB 内置存储，可用于设置、少量公共缓存和诊断记录。
- TF 卡留给将来的大量截屏、主题、照片、动画或长期日志；4.3B 到货后再验证卡槽。

### 后续开发边界

- 已完成隐私状态机和协议内核，实际 BLE GATT 服务仍需接入 ESP-IDF 蓝牙栈。
- 天气、预警和指数的数据结构已经确定，Wi-Fi 配网与正式接口适配待后续阶段实现。
- Mac 助手待阶段 E 开始，先完成系统状态和控制动作，再接入 Codex、Claude Code 与媒体状态。

## 2026-08-17：microSD 纳入正式方案

### 新决定

- 用户已经购买存储卡，后续将 microSD 作为日志、诊断导出、截屏和大型资源的主要存储位置。
- 不再以少量 Flash 占用作为功能取舍的主要依据，开发时优先保证界面响应、蓝牙心跳和长期运行性能。
- 板载 Flash 继续保存固件、启动资源、设置、绑定信息和少量关键故障记录，确保未插卡时仍可启动和运行核心功能。

### 实现要求

- 日志通过内存队列异步批量写卡，不在界面、触摸或蓝牙回调中同步写文件。
- 支持日志轮换、存储卡状态检测、拔卡降级、写满保护和故障后恢复。
- 日志过滤敏感字段，禁止保存 Wi-Fi 密码、绑定密钥、通知正文、AI 提示词与回答。
