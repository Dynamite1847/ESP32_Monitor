# ESP32_Monitor

一块面向办公桌使用的 800×480 横屏触摸控制台。ESP32 通过 Wi-Fi 获取时间、天气、预警和 A 股指数；所有 Mac 状态与控制通过低功耗蓝牙传输。

## 当前状态

- ESP-IDF v5.5.5 开发环境已安装并完成编译验证。
- 4.3 与 4.3B 共用一套硬件适配层，当前默认目标为 4.3B（最终硬件）。
- 六个日常页面、页面库、设置与设备诊断、固定程序坞和左右滑动已经进入固件。
- CJK 后备字库已外置到 SD（LVGL 二进制字体，开机后台加载），应用镜像从 4.62MB 降到约 1.96MB，6MB 分区剩余 67%。
- 页面数据采用局部控件更新，常规状态变化不会反复重建整页。
- 公共与私有数据使用统一状态模型；开机公共数据显示“等待联网更新”，真实数据到达后替换（不再显示模拟数据）。
- 蓝牙 GATT 服务、分片传输、CRC 校验、隐私锁定、6 秒心跳超时状态机与挑战认证已经实机验证。
- macOS 菜单栏助手已建立，能够扫描、连接、发现特征、读取设备状态并在断开后自动重连；Wi-Fi 密码与天气 API Key 保存在钥匙串。
- Mac 系统监控、60 秒趋势、前台应用快捷键、媒体键、Codex 用量与 AI 任务数量已经接通蓝牙协议。
- Wi-Fi 配网、NTP、和风天气（gzip 自解压）、气象预警与六个 A 股指数已在 4.3B 实机拉到真实数据上屏。
- microSD 自动挂载、异步日志、轮转和隐私过滤内核已经实现并实机验证。
- 任务看门狗已开启（卡死自恢复重启）；主机侧自动测试、Swift 编译与固件全量编译通过。
- 最新固件已实机验证（4.3B）：屏幕、触摸、左右滑动、中文显示、PSRAM、蓝牙认证、Wi-Fi、真实天气/行情均确认，单次启动无重启/看门狗误触发。

## 工程目录

```text
firmware/                 ESP32-S3 固件
├── components/
│   ├── app_model/        页面统一数据模型与模拟数据
│   ├── ble_protocol/     蓝牙逻辑帧编解码与 CRC
│   ├── board/            4.3 / 4.3B 屏幕、触摸和背光适配
│   ├── http_fetch/       证书校验 HTTPS 与响应上限
│   ├── market/           上交所与深交所指数
│   ├── network/          Wi-Fi、配网、重连与 NTP
│   ├── privacy/          认证、心跳与锁定状态机
│   ├── storage/          microSD 挂载、异步日志与存储策略
│   ├── ui/               LVGL 页面、程序坞和手势
│   └── weather/          和风天气、预报与预警
├── scripts/              主机测试与编译前检查
└── tests/host/           无开发板可运行的测试
protocol/                 设备与 Mac 助手的协议
macos-helper/             macOS 菜单栏蓝牙助手
docs/                     规划、架构、环境和开发记录
```
